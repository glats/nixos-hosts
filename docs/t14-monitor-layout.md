# T14 Monitor Layout

## Architecture

Monitor management is handled by [HyprDynamicMonitors](https://github.com/fiffeek/hyprdynamicmonitors) (HDM v1.4.0), an event-driven daemon that detects lid state via UPower D-Bus and monitor hotplug via native Hyprland IPC. HDM matches the current set of connected monitors + lid state against a TOML profile config (`hosts/t14/hdm/config.toml`) and writes the matching static Hyprland config fragment to `~/.config/hypr/config.d/99_autogenerated-monitors.conf`. Hyprland picks this up via a `source =` directive in `monitors.nix`.

**Key properties**:
- **No polling**: Event-driven via Hyprland socket2 and UPower D-Bus signals
- **EDID-based matching**: `description` (EDID) strings, not connector names (survives kernel re-enumeration)
- **Debounced**: 1500ms debounce absorbs rapid dock/undock transients
- **Fallback**: Generic `monitor = ,preferred,auto,1` when no profile matches
- **Profile applications are atomic**: HDM writes the matching config, Hyprland hot-reloads

## Positions

```
y=0     ╔══════════════════╗
        ║   DP-5 (rotated) ║  AOC 24P1W1 (1080×1920, transform 1)
        ║   ws 1,4,7...    ║  x=0, y=0
y=420   ║   ┌──────────┐ ┌──────────┐ ┌──────────┐
        ║   │ DP-4     │ │ DP-3     │ │ eDP-1    │
        ║   │ ws 2,5.. │ │ ws 3,6.. │ │ (free)   │
y=1499  ║   └──────────┘ └──────────┘ └──────────┘
        ║                  ║
y=1919  ╚══════════════════╝
        x=0      x=1080     x=3000     x=4920
```

- DP-5 (rotated portrait): 1080px wide effective → y=[0,1919]
- DP-4, DP-3, eDP-1: 1920×1080, y=420 (centered vertically with rotated DP-5)
- y=420 eliminates cursor dead zone when crossing between monitors

## eDP-1 Behavior

State driven by HDM profile selection (UPower lid events):

| Condition | eDP-1 Position | Profile |
|-----------|----------------|---------|
| Lid open + docked | 4920x420 (enabled) | docked_lid_open |
| Lid closed + docked | -30000x0 (off-screen, NOT disabled) | docked_lid_closed |
| Lid open + undocked | 0x0 (enabled) | undocked_lid_open |
| Lid closed + undocked | 0x0 (enabled, pre-suspend) | undocked_lid_closed |

eDP-1 is never disabled — parking it at `-30000x0` preserves workspace state
(Hyprland #1274: disabling eDP-1 loses workspace bindings).

## Desc Identifiers (for waybar, window rules, etc.)

```bash
# Get current connector names
hyprctl monitors -j | jq '.[] | {name, desc: .description}'

# Full monitor info
hyprctl monitors -j | jq '.[] | {name, desc, x, y, transform, activeWorkspace}'
```
