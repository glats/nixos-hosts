# AGENTS.md - NixOS Multi-Host Configuration

## Overview

- **Hosts**: `rog` (desktop + nvidia + server), `thinkcentre` (headless + xrdp), `t14` (laptop, Omarchy/Hyprland), `mact2` (macOS via nix-darwin)
- **User**: glats (linux hosts), jcuzmar (mact2)
- **Stack**: NixOS Flakes + Home Manager + sops-nix + nix-darwin

## Quick Commands

| Task | Command |
|------|---------|
| Build & switch | `nixos-build` |
| Safe (check→build→dry→switch) | `nixos-build safe` |
| Dry run | `nixos-build dry` |
| Validate | `nix flake check --no-build` |
| Format (full repo) | `format-nix` |
| Format (single file) | `nix fmt -- <path>` |

`nixos-build` auto-detects hostname, worktree, and `nh` vs `nixos-rebuild`. Use `--raw` to force `nixos-rebuild`.

## Project Structure

```
hosts/{hostname}/default.nix     # Host entry — imports modules directly
hosts/{hostname}/services/       # Host-specific services (rog has many)
modules/profiles/                # base.nix → desktop.nix → server.nix (chain)
modules/base/                    # Core system (users, nix, sops, zsh, etc.)
modules/desktop/                 # fonts, i18n, kmscon
modules/features/                # boot.nix, conky/, services/
modules/hardware/                # nvidia, amd-laptop, asus-fan-control
modules/networking/              # openssh, firewall, wol, avahi
modules/virtualisation/          # docker, libvirt
home-linux/                      # Home Manager modules (linux)
home-darwin/                     # Home Manager modules (macOS)
shared/                          # Cross-platform HM modules (opencode, sops, tmux)
darwin/                          # nix-darwin system modules (homebrew, settings)
lib/                             # mkHost.nix, mkDarwinHost.nix, packages.nix
overlays/                        # linux.nix, darwin.nix (imported via flake.nix)
pkgs/                            # Custom package derivations
bin/                             # Shell scripts (nixos-build, format-nix, git-flow, etc.)
secrets/                         # sops-nix (encrypted — never edit directly)
```

## Boundaries

- ALWAYS: Run `nix flake check --no-build` before finishing
- ALWAYS: Run `format-nix` after editing .nix files
- ALWAYS: Ask before running `nixos-build switch` — builds can take a long time
- ASK: Before editing `hardware-configuration.nix` (auto-generated)
- NEVER: Edit files in `secrets/` directly (use `sops secrets/secrets.yaml`)

## Critical Rules

1. **hardware-configuration.nix**: Never edit — auto-generated by `nixos-generate-config`
2. **Profile chain**: `base.nix` → `desktop.nix` → `server.nix`. Hosts import the profile they need (e.g., rog imports `server.nix` which pulls in desktop and base transitively)
3. **New module**: Add to the appropriate `modules/` subdirectory. Import it in the host's `default.nix` or in a profile if shared
4. **`features/*` subcategories**: No `default.nix` — import services directly (e.g., `../../modules/features/services/xrdp.nix`)
5. **Host-specific services**: Place in `hosts/{hostname}/services/`, import in that host's `default.nix`
6. **Unfree packages**: Add to `allowUnfreePackages` in host config
7. **Secrets**: Use `sops secrets/secrets.yaml` to edit
8. **overlays.nix**: NOT a module — imported via `import` in `flake.nix`, not `imports`
9. **Home Manager**: NixOS-integrated via `modules/base/home-manager.nix`. Canonical shared module list is in `home-linux/shared-modules.nix` (single source of truth — do not duplicate)
10. **Formatter**: Use `format-nix` for full-repo, `nix fmt -- <path>` for single file. Never run `nix shell nixpkgs#nixfmt-rfc-style --command nixfmt-rfc-style ...`
11. **t14 (Omarchy)**: Uses `omarchy-nix` module + `nixos-hardware` T14 profile wired via `flake.nix` `extraModules`. Home-manager config is in `hosts/t14/home/omarchy.nix`, not the shared HM module list
12. **mact2 (macOS)**: Built via `mkDarwinHost` from `lib/mkDarwinHost.nix`. Darwin system modules in `darwin/`, home-manager modules in `home-darwin/`
13. **Home-conditional modules**: Host-conditional HM modules (conky-rog, openfang) are NOT in `shared-modules.nix` — appended per-host in `flake.nix` `homeConfigurations`
