# ROM Download Sources — URL Templates

## 1. Edge Emulation (edgeemu.net)
Browse: `https://edgeemu.net/browse/{slug}/{letter}/`
Download: `https://edgeemu.net/download/{slug}/{filename}.zip`
Slugs: nintendo-nes, nintendo-snes, nintendo-n64, nintendo-gb, nintendo-gbc, nintendo-gba, nintendo-nds, sega-genesis, sony-psx

## 2. Internet Archive (archive.org)
Search: `ia search "{collection}"`
Download: `https://archive.org/download/{identifier}/{filename}`
Collections: ni-roms (cartridges), psx-redump-chd-usa (PSX), mame-merged (MAME)

## 3. MiNERVA (minerva-archive.org)
Browse: `https://minerva-archive.org/browse/{collection}/`
Download: torrent via aria2c --select-file={id}
Collections: No-Intro (cartridges), Redump (CD), MAME (arcade), FinalBurn Neo
