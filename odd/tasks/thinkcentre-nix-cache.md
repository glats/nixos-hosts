Objective: turn thinkcentre into a Nexus-style LAN Nix binary cache that periodically prewarms every host closure, reachable off-LAN through rog nginx with basic auth.
Branch: feat/thinkcentre-nix-cache (base origin/master b9cd3830) · Delivery: single-pr (user owns push/PR) · Test runner: `go -C pkgs/nixos-scripts test ./...` plus `nix eval`/`nix flake check --no-build`.

## Specs

- S1 Server on thinkcentre: Harmonia serves thinkcentre's `/nix/store` (default bind `[::]:5000`, signed with a sops-managed key via `services.harmonia.cache.signKeyPaths`). User: "quiero que thinkcentre se transforme en un cache con todos los paqutes que usa mi nix para que los build sean mas rapidos. los builds para rog, t14, macm5 y thinkcentre".
- S2 Nexus-style proxy: ncps (`services.ncps`, default `:8501`) in front of Harmonia (`http://127.0.0.1:5000`), cache.nixos.org and the cachix caches already listed in `shared/cachix-settings.nix` and `linux/system/base/cachix.nix`; `cache.hostName` required; `cache.secretKeyPath` from sops so the public key is known in the repo; `cache.maxSize` + `cache.lru.schedule` bound disk (assumption: 100G until disk size is checked). User: "quiero que de forma periodca y ademas estilo nuexs eso quiero".
- S3 Periodic idle prewarm: Go command (repo rule: operational CLIs in Go, `pkgs/nixos-scripts/cmd/nix-cache`, logic in `internal/`), subcommand `prewarm`, run by a systemd timer on thinkcentre only when idle (load-average guard; `nix.daemonCPUSchedPolicy = "idle"`, `nix.daemonIOSchedClass = "idle"`). It builds with GC roots (out-links under its state dir): (a) the current `origin/master` lock and (b) a scratch copy after `nix flake update`, for `nixosConfigurations.{rog,t14,thinkcentre}` toplevels and `homeConfigurations.{rog,t14,thinkcentre}` activation packages. User: "lo que quiero es que thinkcetre cuanod no este haciendo nada, se vaya actualizando todos los pquetes que funcione como un nexus". Chosen option: "Lock actual + próximo upgrade".
- S4 macm5 (aarch64-darwin, thinkcentre cannot build it): prewarm substitutes `darwinConfigurations.macm5` and `homeConfigurations.macm5` substitute-only (`--option max-jobs 0`, `--keep-going`, best-effort); macm5 pushes what it builds locally with `nix-cache push` (`nix copy --to ssh-ng://glats@thinkcentre`), best-effort after a successful darwin `nixos-build`. Requires `nix.settings.trusted-users` to include `glats` on thinkcentre only. Chosen option: "Sustituir upstream + push desde macm5".
- S5 Clients with priorities: rog, t14 and macm5 add `http://172.16.0.11:8501?priority=30` (LAN ncps) and `https://cache.glats.org?priority=45` (remote, only for paths not upstream); upstream caches stay at their default priority 40; trust ncps + Harmonia public keys. thinkcentre must NOT use its own cache as substituter. macm5 uses `determinateNix.customSettings` (Determinate Nix, `nix.enable = false`), not `nix.settings`. Off-LAN must degrade silently through existing `fallback = true` / `connect-timeout = 5`. User: "cuando este afuera si no lo encuentre no deberian ahber problema"; "aveces aprovehcar la red lan que es mas rapdia".
- S6 Off-LAN access via rog, no modem change: rog nginx vhost `cache.glats.org` (existing wildcard ACME `*.glats.org`, ddclient `*.glats.org`) with basic auth proxying to `http://172.16.0.11:5000` (Harmonia). User: "rog ya tiene virtual hsots asociado en el modem. para nginx glats.org. podemos ahcer algo por alli cuanod los hosts no esten en la mism red lan".
- S7 Auth and secrets: basic auth + netrc, secrets in sops per host. User: "me gusta basic auth netrc y aprovechar sops por hosts". htpasswd on rog (`secrets/host/rog/nix-cache.yaml`), netrc on t14 and macm5 (`secrets/host/t14/…`, `secrets/host/macm5/…` — needs new `.sops.yaml` creation rules placed before generic rules), signing keys on thinkcentre (`secrets/host/thinkcentre/nix-cache.yaml`). Never decrypt sops secrets; generate and encrypt only. Open question from the user: "hay otrao tipo de auth o tiene que ser basic?" — answer pending (Nix HTTP substituters authenticate only through `netrc-file`; alternatives are SSH stores or network-level access such as WireGuard).
- S8 Docs: add `docs/nix-cache.md` runbook (architecture, priorities, prewarm, push, key rotation) and update help text for the new command.
