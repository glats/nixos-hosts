# rog shutdown (unbiased restart)
Objective: rog reliably reaches physical power-off on `systemctl poweroff`, re-derived from fresh evidence; rog moves to the newest kernel in the nixpkgs pin.
Branch: feature/rog-shutdown. Delivery: ask-on-risk. Runner: Nix evaluation/build and `go -C pkgs/nixos-scripts test ./...`; live trials are user-run on rog.

## Specs
S1. "yo creo que hay que retomarlo sin bias" / "full odd diria yo sin bias". Restart the rog shutdown work from evidence: earlier conclusions (firmware S5 boundary, NVIDIA deprioritized, AML bypass disproven, EFI fallback unreliable) are hypotheses to re-test, not facts. Separate observed facts from inferences, measure every outcome objectively, change one variable per trial. Acceptance carried from OpenSpec 4.5: three consecutive unattended poweroffs each reach physical-off with evidence and no manual intervention.
S2. "ademas quiero usar la ulktiam version de linux ya. la 7 creo"; amended by "ojala version 7 pero con lo menos de build local. que opciones tneemos?" and the choice "7.1.9 sin parches (Recomendado)". rog uses `linuxPackages_7_1` (7.1.9) without local driver patches; `nvidia legacy_580`, `acpi_call` and `rog_efi_poweroff` must build against it. Move to 7.2 once nixpkgs fixes NVIDIA 580 on 7.2 (#554125). Other hosts unchanged. Activation is the user's (`nixos-build`).
S3. "te paerce si me creas uno scripts con todas las pruebas env ez de yo ejecutar manualk? asi hago com sudo test-shutdowen. no se y vamos probando vale?" A Go command `test-shutdown` (repo rule: operational tools are Go in pkgs/nixos-scripts) that applies one T4 trial at runtime, records it persistently with boot id and kernel, leaves a kmsg breadcrumb, and powers off; lets the user record the observed outcome after the next boot; lists trials and history. Manual trials (outside NixOS, EC reset) only print instructions and never power off. Dry-run shows steps without changing anything.
