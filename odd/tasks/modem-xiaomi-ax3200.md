- Objective: verify feasibility (done) and prepare a safe, evidence-backed procedure to unlock SSH and/or flash OpenWrt on the user's Xiaomi AX3200 RB01.
- Branch/worktree: `feature-modem` (worktree of the nixos-hosts repo)

Assumptions:
- A1: Router is a user-owned home gateway; flashing is executed only with explicit user go-ahead in a supervised session (home network outage of ~10–20 min).
- A2: User preference is the OpenWrt path; the brick-risk check (S2) was requested before committing to it.
- A3 (user-provided 2026-10-17): "ojo que si me quedo sin internet no tengo acceo para sguir interactuando contigo" — if home internet drops, the user loses assistant access. Design consequence: Phase 1 must be zero-downtime; Phase 2 must be executable from the offline runbook alone, with a pre-staged recovery kit on the user's disk and no assistant dependency during the outage window.
