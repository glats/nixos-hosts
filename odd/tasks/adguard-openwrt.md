# Migration of AdGuard Home: OnePlus 5 (postmarketOS) → router OpenWrt

Objective: move AdGuard Home from the oneplus5 device (172.16.0.12, pmOS, systemd, /usr/bin/adguardhome) to the OpenWrt router (172.16.0.1), preserving the complete rule set, persistent clients and Quad9 doT upstreams, making the router self-contained for DNS, and freeing the OnePlus.
Branch: feature/adguard. Test runner: live-network verification battery (dig/dnsmasq/nft/HTTP), router procd.
Delivery strategy: ask-on-risk (self-contained migration; no push/PR decisions for the user).

## Specs

- S1 (user verbatim: "dale vamos con mover adguard de lado"): AdGuard Home runs on the OpenWrt router bound to 172.16.0.1:53 with the web UI at 172.16.0.1:3000; the config is the migrated `/etc/adguardhome/AdGuardHome.yaml` from oneplus5 (253 lines, schema_version 34) with bind patches only. Rules preserved verbatim: user_rules (15 rules incl. android-tv doubleclick/firebase/netflix/twitch/sentry etc. with `$client=` qualifiers), clients.persistent (android-tv, android-tv-2 → ids incl. 172.16.0.182), filters [] / rewrites [] unchanged, Quad9 doT upstreams tcp://9.9.9.10 + tcp://149.112.112.10 parallel mode, DNSSEC enabled, cache 32MB optimistic.
- S2 (no-loop DNS architecture): router dnsmasq moves to port 5353 (DHCP-only role preserved on default ports), AGH owns LAN :53; the router's WAN resolver list no longer contains 172.16.0.12 (9.9.9.9 + 149.112.112.10 only); DHCP option 6 for the LAN becomes '6,172.16.0.1' (dnsmasq defaults). Zero references to 172.16.0.12 as DNS remains in the house plumbing after validation.
- S3 (service lifetime): AGH on the router runs as a procd init script, starts on boot after network, auto-restarts on failure; `/etc/init.d/adguardhome` with procd_add_reload_trigger inside network/dnsmasq boundaries.
- S4 (safe cutover order): AGH starts on the router BEFORE the DHCP option flip; oneplus5's `adguardhome.service` only stops (`systemctl disable --now`) AFTER the router's AGH is verified answering :53 — the house never loses DNS mid-migration (old resolver .12 remains live as fallback until the flip).
- S5 (stats/fresh-instance rule): `/var/lib/adguardhome` (312.7 MB of querylog/stats on the oneplus5) is NOT copied to the router (83 MB overlay budget); the router instance starts with fresh querylog/stats; historical stats stay archived on the oneplus5 device.
