# Design: greeter-monitor-select

## Technical Approach

Extend the existing `greetd-regreet-start` shell script in `omarchy-nix/modules/nixos/system.nix` with a monitor selection phase that runs BEFORE the current eDP-1 disable logic. Add a `focusMonitor` option to the `omarchy.greeter` submodule in `config.nix`. Set `focusMonitor = "LEN G24"` in t14's host config.

The script uses stable Hyprland IPC (`hyprctl monitors -j`, `hyprctl keyword monitor X,disable`, `hyprctl dispatch focusmonitor X`) — the only mechanism that survives Hyprland 0.53+ `windowrulev2` deprecation and 0.55+ Lua migration. Empty `focusMonitor` (default) preserves pre-change behavior on all hosts.

## Architecture

```
greetd.service
  └─ default_session: start-hyprland -- --config /etc/greetd/hyprland.conf
       └─ Hyprland parses /etc/greetd/hyprland.conf (generated by system.nix)
            ├─ monitor = desc:... lines (from cfg.greeter.monitors)
            ├─ env = XCURSOR_THEME,... (from cfg.greeter.cursor)
            ├─ exec-once = wayvnc ... & (if wayvnc.enable)
            └─ exec-once = greetd-regreet-start (the script)
                 │
                 ├─ PHASE 1: Monitor selection (NEW)
                 │    ├─ Retry loop: hyprctl monitors -j until non-empty (10×0.1s)
                 │    ├─ jq filter: match description contains focusMonitor
                 │    ├─ Disable loop: hyprctl keyword monitor <other>,disable
                 │    └─ Focus: hyprctl dispatch focusmonitor <target>
                 │
                 ├─ PHASE 2: eDP-1 disable (EXISTING, unchanged)
                 │    └─ /sys/class/drm scan → hyprctl keyword monitor eDP-1,disable
                 │
                 └─ PHASE 3: Launch (EXISTING, unchanged)
                      ├─ regreet
                      └─ hyprctl dispatch exit
```

## Architecture Decisions

| Decision | Choice | Alternative | Rationale |
|----------|--------|-------------|-----------|
| Mechanism | Script-based `hyprctl keyword monitor X,disable` | `windowrule monitor` (B), nwg-hello (C) | windowrulev2 is a hard error in 0.53+; windowrule has unfixed focus bugs (#8942/#9365/#8262); nwg-hello is Plan B (~80 lines + new module) |
| Target matching | Description substring via `jq contains` | Exact description match; monitor name (DP-*) | Substring is stable across EDID variations; DP-* names change on re-dock |
| Option type | `lib.types.str` with default `""` | `nullOr str` | Empty string is simpler for shell interpolation; `if [ -n "$FOCUS" ]` is the natural guard |
| Retry strategy | `for i in $(seq 1 10); sleep 0.1` | Fixed `sleep 1` | 10×0.1s = 1s max wait but breaks early on success; avoids fixed delay on fast boots |
| Interpolation | `${cfg.greeter.focusMonitor}` (Nix-time) | `\${cfg.greeter.focusMonitor}` (shell-time) | Value is known at build time; Nix injects the literal string into the script |

## Nix String Interpolation

Inside `pkgs.writeShellScript "greetd-regreet-start" ''...''`, the `''...''` is a Nix multiline string. `${...}` is evaluated by Nix at build time. Shell variables must use `\${...}` to escape Nix interpolation.

For `focusMonitor`: we want Nix to inject the literal value at build time:
```nix
FOCUS=${cfg.greeter.focusMonitor}
```
This produces `FOCUS=LEN G24` in the generated script when the option is set, or `FOCUS=` when empty (default).

For shell variables like `$TARGET_MON`, we escape: `\${TARGET_MON}` → `${TARGET_MON}` in output.

## Interfaces / Contracts

### Nix Option (config.nix, after line 329)

```nix
focusMonitor = lib.mkOption {
  type = lib.types.str;
  default = "";
  example = "LEN G24";
  description = ''
    Description substring of the monitor that should host ReGreet when docked.
    Matches against the `description` field from `hyprctl monitors -j` using
    jq `contains`. Empty string (default) skips monitor selection entirely,
    preserving pre-change behavior.
  '';
};
```

### Shell Script (system.nix, lines 196–207 replacement)

```bash
greeterScript = pkgs.writeShellScript "greetd-regreet-start" ''
  # --- PHASE 1: Monitor selection (focusMonitor) ---
  FOCUS=${cfg.greeter.focusMonitor}
  if [ -n "$FOCUS" ]; then
    # Wait for Hyprland to enumerate monitors (up to 1s)
    for i in $(seq 1 10); do
      ${pkgs.hyprland}/bin/hyprctl monitors -j 2>/dev/null \
        | ${pkgs.jq}/bin/jq -e 'length > 0' >/dev/null 2>&1 && break
      sleep 0.1
    done

    # Find target monitor by description substring
    TARGET_MON=$(
      ${pkgs.hyprland}/bin/hyprctl monitors -j 2>/dev/null \
        | ${pkgs.jq}/bin/jq -r --arg d "$FOCUS" \
          '.[] | select((.description // "") | contains($d)) | .name' \
        | head -1
    )

    if [ -n "$TARGET_MON" ] && [ "$TARGET_MON" != "null" ]; then
      # Disable all externals except target (leave eDP-* for Phase 2)
      for m in $(${pkgs.hyprland}/bin/hyprctl monitors -j 2>/dev/null \
          | ${pkgs.jq}/bin/jq -r '.[].name'); do
        case "$m" in
          eDP-*) ;;
          "$TARGET_MON") ;;
          *) ${pkgs.hyprland}/bin/hyprctl keyword monitor "$m,disable" >/dev/null 2>&1 ;;
        esac
      done
      ${pkgs.hyprland}/bin/hyprctl dispatch focusmonitor "$TARGET_MON" >/dev/null 2>&1
    fi
  fi

  # --- PHASE 2: eDP-1 disable (existing) ---
  for s in /sys/class/drm/card*-*/status; do
    case "$s" in *-eDP-*) continue;; esac
    read -r st < "$s" 2>/dev/null
    if [ "$st" = connected ]; then
      ${pkgs.hyprland}/bin/hyprctl keyword monitor eDP-1,disable
      break
    fi
  done

  # --- PHASE 3: Launch (existing) ---
  ${pkgs.regreet}/bin/regreet
  ${pkgs.hyprland}/bin/hyprctl dispatch exit
'';
```

## Error Handling Flow

```
focusMonitor set?
  ├─ NO  → skip Phase 1 entirely → Phase 2 → Phase 3 (pre-change behavior)
  └─ YES → retry hyprctl monitors -j
              ├─ succeeds (non-empty JSON) → jq filter
              │    ├─ match found → disable loop → focusmonitor → Phase 2 → Phase 3
              │    └─ no match (TARGET_MON empty/null) → skip to Phase 2 → Phase 3
              └─ fails after 10 retries → skip to Phase 2 → Phase 3
```

All `hyprctl`/`jq` calls redirect stderr to `/dev/null` and use `2>/dev/null` guards. Every failure path falls through to Phase 2 (existing eDP-1 logic) → Phase 3 (regreet launch). ReGreet ALWAYS launches.

## Migration / Rollout

No migration required. `focusMonitor` defaults to `""` (empty) — all existing hosts behave identically. t14 opts in with one line. Rollback: remove the `focusMonitor` line or set `""`.
