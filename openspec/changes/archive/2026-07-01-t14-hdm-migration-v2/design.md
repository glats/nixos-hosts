# Design: T14 HDM Migration v2

## Technical Approach

Replace T14's ~290-line custom monitor stack with HyprDynamicMonitors v1.4.0 by: (1) wiring the upstream HDM Home Manager module from the flake input, (2) deploying TOML profiles + static hyprconfigs via the module's `config` and `extraFiles` options, (3) stripping all legacy daemon/activation/udev/bindl code, and (4) pointing `monitors.nix` at HDM's output via a `source` directive. All 6 v1 bugs addressed by construction.

## Architecture Decisions

### Decision: Flake input with `follows`

| Option | Tradeoff | Decision |
|--------|----------|----------|
| `inputs.nixpkgs.follows = "nixpkgs"` | Shares dependency tree, smaller closure | **Chosen** — matches `home-manager`, `sops-nix`, `omarchy-nix` convention |
| Independent nixpkgs pin | Isolated but larger closure, version drift | Rejected |

### Decision: HM module wiring location

| Option | Tradeoff | Decision |
|--------|----------|----------|
| Add to `home-manager.users.glats.imports` in `hosts/t14/default.nix` | Co-located with host, explicit | **Chosen** — t14 already has inline HM config (line 233-235), does NOT use `modules/base/home-manager.nix` |
| Add to `home-linux/shared-modules.nix` | Shared across hosts | Rejected — HDM is t14-only |

### Decision: Config deployment via HM module options

| Option | Tradeoff | Decision |
|--------|----------|----------|
| `home.hyprdynamicmonitors.config` (inline TOML) + `extraFiles` (hyprconfigs) | Module manages deployment; Nix string interpolation provides absolute paths for `config_file` | **Chosen** — cleanest, no manual `home.file` or `xdg.configFile` |
| Manual `home.file` for TOML + hyprconfigs | More control but duplicates module logic | Rejected |
| `configFile` option | Requires separate file | Rejected — inline `config` allows `${config.home.homeDirectory}` interpolation for `config_file` paths |

### Decision: Source directive with absolute path

Use `config.home.homeDirectory + "/.config/hypr/config.d/99_autogenerated-monitors.conf"` in `monitors.nix` `extraConfig`. Uses HM's `config.home.homeDirectory` (resolves to `/home/glats`), NOT `~` (BUG 1 fix — hyprlang `source` does not expand `~`).

### Decision: Workspace rules ownership

Remove `mkWorkspaceRules` entirely from `monitors.nix`. Workspace rules move to static hyprconfigs (per-profile). This eliminates BUG 6 (duplicate `default:true` for ws 1-3 on both externals and eDP-1).

## Data Flow

```
Nix build ──→ home.file symlinks:
  │  ~/.config/hyprdynamicmonitors/config.toml  (read-only, TOML)
  │  ~/.config/hypr/hdm-profiles/*.conf          (read-only, 5 hyprconfigs)
  │
  ▼
HDM daemon (systemd user service)
  │ reads config.toml → selects profile → reads hyprconfig
  │ writes to ~/.config/hypr/config.d/99_autogenerated-monitors.conf
  │
  ▼
monitors.nix extraConfig:
  source = /home/glats/.config/hypr/config.d/99_autogenerated-monitors.conf
  │
  ▼
Hyprland compositor (monitor=, workspace= directives)
```

## Interfaces / Contracts

### HDM HM module options used

```nix
home.hyprdynamicmonitors = {
  enable = true;
  package = inputs.hyprdynamicmonitors.packages.${pkgs.system}.default;
  config = builtins.readFile ./hdm/config.toml;  # or inline with interpolation
  extraFiles = {
    "hypr/hdm-profiles/docked-lid-open.conf" = ./hdm/hyprconfigs/docked-lid-open.conf;
    "hypr/hdm-profiles/docked-lid-closed.conf" = ./hdm/hyprconfigs/docked-lid-closed.conf;
    "hypr/hdm-profiles/undocked-lid-open.conf" = ./hdm/hyprconfigs/undocked-lid-open.conf;
    "hypr/hdm-profiles/undocked-lid-closed.conf" = ./hdm/hyprconfigs/undocked-lid-closed.conf;
    "hypr/hdm-profiles/fallback.conf" = ./hdm/hyprconfigs/fallback.conf;
  };
  installExamples = false;
  extraFlags = [ "--enable-lid-events" ];
};
```

### UPower assertion

```nix
assertions = [{
  assertion = config.services.upower.enable;
  message = "HDM lid events require services.upower.enable = true (set in modules/hardware/amd-laptop.nix)";
}];
```

## Testing Strategy

| Layer | What to Test | Approach |
|-------|-------------|----------|
| Build | `nix flake check --no-build` passes for all hosts | Automated — verifies no eval errors |
| Format | `format-nix` clean | Automated |
| Grep gate | No references to removed patterns | `grep -r "monitor-lid-validator\|settings.conf\|udev-settle\|seedHyprSettings" hosts/t14/` returns empty |
| Manual | 4-state monitor matrix (docked/undocked × lid open/closed) | On t14 hardware after `nixos-build switch` |

## Migration / Rollout

No data migration. Single commit to master. HDM destination path (`~/.config/hypr/config.d/99_autogenerated-monitors.conf`) is outside HM management — clean removal with no stale symlinks. Rollback: revert commit + `nixos-build switch`.
