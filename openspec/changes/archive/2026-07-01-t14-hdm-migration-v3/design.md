# Design: T14 HDM Migration v3

## Technical Approach

Replace T14's ~290-line custom monitor stack with HyprDynamicMonitors v1.4.0. Wire the upstream HM module from a new flake input; deploy TOML profiles + 5 static hyprconfigs via `configFile`/`extraFiles`; strip all legacy daemon/activation/udev/bindl code; point `monitors.nix` at HDM's output via `source`. All 6 v1 bugs fixed by construction. v3 supersedes v2 by consolidating workspace rules into hyprconfigs (BUG 6), verifying the real HDM interface against live upstream docs, and adding a UPower assertion as a hard gate.

## Architecture Decisions

### D1: Flake input wiring

| Option | Tradeoff | Decision |
|--------|----------|----------|
| `inputs.nixpkgs.follows` only | Smaller closure | Partial — needs HM follows too |
| `nixpkgs.follows` + `home-manager.follows` | Aligns HDM HM build with our HM | **Chosen** — matches `omarchy-nix` convention |
| Independent pin | Isolated but version drift | Rejected |

Add `hyprdynamicmonitors.url = "github:fiffeek/hyprdynamicmonitors"` in the NixOS-only input block (~after `nixos-hardware`).

### D2: HM module import site

| Option | Tradeoff | Decision |
|--------|----------|----------|
| `users.glats.imports` in `hosts/t14/default.nix` | Co-located, t14-only | **Chosen** — t14 has inline HM (L233), doesn't use `modules/base/home-manager.nix` |
| `home-linux/shared-modules.nix` | Shared across hosts | Rejected — forces dead imports on rog/thinkcentre |

### D3: Config deployment (verified against live upstream docs)

| Option | Tradeoff | Decision |
|--------|----------|----------|
| `configFile` + `extraFiles` | Module manages symlinks + systemd | **Chosen** — matches upstream HM contract |
| `config` (inline) | Needs `${config.home.homeDirectory}` interpolation for paths | Rejected — HDM resolves `config_file` relative to `~/.config/hyprdynamicmonitors/`, so relative paths need no interpolation |
| Manual `home.file` | Duplicates module logic | Rejected |

`extraFiles = { "hyprdynamicmonitors/hyprconfigs" = ./hdm/hyprconfigs; }` deploys 5 `.conf` under `~/.config/hyprdynamicmonitors/hyprconfigs/`; `extraFlags = [ "--enable-lid-events" ]`.

### D4: Source directive (BUG 1 fix)

In `monitors.nix` `extraConfig`, use `config.home.homeDirectory + "/.config/hypr/config.d/99_autogenerated-monitors.conf"` — an absolute path. NOT `~` (hyprlang `source` doesn't expand it). HDM's `[general].destination` keeps the literal `$HOME` string (HDM expands at runtime).

### D5: Workspace rules architecture

| Option | Tradeoff | Decision |
|--------|----------|----------|
| Rules live in each profile's `.conf` | Each profile owns its `workspace=` directives; no duplication possible | **Chosen** — fixes BUG 6 by construction |
| Keep `mkWorkspaceRules` in Nix, filter `w > 3` | Two sources of truth; `default:true` collisions persist | Rejected |
| Nix `settings.workspace` + conditionals | Same `settings.conf`/hyprlang-`if` fragility | Rejected |

Each `.conf` writes its own `workspace =` lines; `mkWorkspaceRules` and `workspace = mkWorkspaceRules` are fully removed.

### D6: What to strip (exact)

| File | Removed |
|------|---------|
| `hosts/t14/home/default.nix` | `home.activation.seedHyprSettings`, `xdg.configFile"...udev-settle.conf"`, `systemd.user.services.monitor-lid-validator`, `home.file.".local/bin/monitor-lid-validator.sh"` |
| `hosts/t14/home/hypr/monitors.nix` | `mkWorkspaceRules` let-binding, `workspace = mkWorkspaceRules`, ALL `extraConfig` (both `bindl`, both hyprlang `if/endif` blocks, `source` to settings.conf) |
| `hosts/t14/home/scripts/monitor-lid-validator.sh` | Entire file (71 lines) |

### D7: UPower assertion

Add `assertions = [{ assertion = config.services.upower.enable; message = "..."; }]` in `hosts/t14/default.nix`. Hard build-fail gate — HDM lid events silently degrade without UPower.

## Data Flow

```
Hyprland
  └─ source = /home/glats/.config/hypr/config.d/99_autogenerated-monitors.conf
       └─ HDM daemon (systemd user, from upstream HM module)
            ├─ config.toml      (Nix-managed, read-only via configFile)
            ├─ *.conf            (Nix-managed, read-only via extraFiles)
            ├─ Hyprland IPC     (monitor add/remove)
            └─ UPower D-Bus      (lid events)

  omarchy-hyprland-monitor-watch (socat — orthogonal, KEPT)
    └─ hyprctl reload on monitoradded>> (benign alongside HDM debounce=1500ms)
```

## Interfaces

### HDM HM config block (upstream-verified)

```nix
home.hyprdynamicmonitors = {
  enable = true;
  configFile = ./hdm/config.toml;
  extraFiles = { "hyprdynamicmonitors/hyprconfigs" = ./hdm/hyprconfigs; };
  extraFlags = [ "--enable-lid-events" ];
  # systemdTarget defaults to graphical-session.target — correct
};
```

The UPower assertion (D7) uses `config.services.upower.enable` as the `assertion` value with a message pointing to `modules/hardware/amd-laptop.nix`.

## Migration / Rollout

Single commit to master; no data migration. HDM destination outside HM management — clean removal. Rollback: `git revert` + `nixos-build switch`.
