# Design: WireGuard client config export to ~/Documents

## Technical Approach

Standalone `bin/export-wireguard-configs` bash script (plain bash + coreutils/findutils/grep + sudo), run manually by `glats`. Copies every root-only `/etc/wireguard/clients/<name>.conf` into `/home/glats/Documents/wireguard/` with `install -o glats -g users -m 600`, idempotently overwriting, and prunes destination `.conf` files with no source counterpart. Registered in `pkgs/nixos-scripts/default.nix` (already on PATH). No new packages, no new module options, `wireguard.nix` untouched.

## Architecture Decisions

| Decision | Choice | Alternatives | Rationale |
|----------|--------|--------------|-----------|
| Read source via sudo | `sudo find` + `sudo install` per file | `sops -d` (legacy scripts), non-sudo `cat` | Source is root:root 600 generated by a root activation script — unlike legacy repo-local secrets decrypted by the user's age key. sudo is the only mechanism that can read it; spec mandates sudo. |
| Single sudo prompt | `sudo -v` up-front, then rely on timestamp cache | Prompt per file | One clean prompt; `sudo -v` failure gives a clear, catchable error before any mutation. |
| Empty-source guard | `[ -z "$src_files" ] && exit 0` BEFORE `mkdir`/prune | treat empty as error | Spec: transient empty source must never wipe existing exports. Early exit also skips `mkdir`. |
| Missing-source guard | `sudo test -d` before any destination op | `test -d` as user | Source dir is root-only; probe under sudo. Fails non-zero with clear stderr, destination untouched. |
| Copy primitive | `install -o -g -m` (single command) | `cp` + `chown` + `chmod` | One idempotent command that copies AND fixes ownership/permissions (proposal + repo convention). |
| Prune compare | `grep -qxF` against newline list | `comm`, hardcoded peer list | No hardcoded list; `grep -qxF` is exact-match, dependency-light. |
| No `lib/common.sh` | Self-contained: inline `set -euo pipefail` + `echo >&2` | source common.sh | Script uses absolute paths only (no `repo_root`); sourcing common.sh would add a needless git dependency. |

## Data Flow

```
sudo -v ──► sudo test -d SRC ──► sudo find SRC (list .conf)
                                       │
                          empty? ──► exit 0 (no touch)
                                       │ non-empty
                          mkdir -p DST │
                                       ▼
            sudo install SRC/<n> ──► DST/<n>   (per file, chown+chmod 600)
                                       │
            find DST (.conf) ──► grep -qxF in src? ──no──► rm
```

## Interfaces / Contracts

**Nix module options interface: NONE.** No option is added, changed, or removed. `linux/system/services/network/wireguard.nix` is not touched; the script reads its runtime output at `/etc/wireguard/clients/` only.

**Script contract** (no CLI arguments; fixed absolute paths; quotes all expansions):

```bash
#!/usr/bin/env bash
# Export WireGuard client configs from the root-only /etc/wireguard/clients/
# into ~/Documents/wireguard/ (glats:users, mode 600). Idempotent: overwrites
# existing exports and prunes configs whose peer was removed from the server.
set -euo pipefail

SRC=/etc/wireguard/clients
DST=/home/glats/Documents/wireguard
OWNER=glats
GROUP=users
MODE=600

# 1. Validate sudo up-front (single prompt; clear failure if auth impossible)
if ! sudo -v; then
  echo "ERROR: sudo authentication failed — cannot read $SRC" >&2
  exit 1
fi

# 2. Source must exist (root-only, so probe via sudo)
if ! sudo test -d "$SRC"; then
  echo "ERROR: source directory not found: $SRC" >&2
  exit 1
fi

# 3. List source configs (root-only read)
src_files=$(sudo find "$SRC" -maxdepth 1 -type f -name '*.conf' -printf '%f\n')

# 4. Empty source is NOT an error: exit 0 and never prune existing exports
if [ -z "$src_files" ]; then
  echo "No client configs in $SRC; destination left untouched."
  exit 0
fi

mkdir -p "$DST"

# 5. Copy (overwrite) each config, fixing ownership and permissions
exported=0
while IFS= read -r name; do
  [ -n "$name" ] || continue
  sudo install -o "$OWNER" -g "$GROUP" -m "$MODE" "$SRC/$name" "$DST/$name"
  exported=$((exported + 1))
done <<< "$src_files"

# 6. Prune destination configs with no source counterpart
pruned=0
while IFS= read -r name; do
  [ -n "$name" ] || continue
  if ! grep -qxF "$name" <<< "$src_files"; then
    rm -f "$DST/$name"
    pruned=$((pruned + 1))
  fi
done < <(find "$DST" -maxdepth 1 -type f -name '*.conf' -printf '%f\n' 2>/dev/null)

echo "Exported $exported config(s) to $DST (pruned $pruned stale)."
```

**Registration** (append in `installPhase`, after the `export-mate-config` block):

```nix
    cp $src/export-wireguard-configs $out/bin/
    chmod +x $out/bin/export-wireguard-configs
```

## Testing Strategy

No test framework (`strict_tdd: false`). Verification is `format-nix` + `nix flake check --no-build` (confirms script is registered in `$out/bin` and package evaluates) plus manual scenario checks on `rog` mapped 1:1 to the spec:

| Scenario | Manual check |
|----------|--------------|
| Happy path | 5 `.conf` present in `~/Documents/wireguard/`, `stat` shows `glats:users` 600 |
| Auto-create dir | run with destination absent → dir + files created |
| Idempotent re-run | second run leaves exactly one `.conf` per peer |
| Removed peer pruned | delete a source `.conf`, re-run → destination copy removed |
| Missing source | `mv` source dir, run → non-zero + stderr, destination intact |
| Empty source | empty source dir, run → exit 0, existing exports untouched |
| sudo failure | non-interactive run without cached creds → non-zero + clear error |
