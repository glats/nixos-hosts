# HDM Profiles Specification

## Purpose

Defines HyprDynamicMonitors (HDM v1.4.0) TOML profiles for t14 monitor layouts across all dock/lid state combinations. Each profile maps to a set of `monitor=` directives with exact coordinates.

## Requirements

### Requirement: Docked+Lid-Open Profile

The system MUST define an HDM profile that activates when all three external monitors (AOC 24P1W1, Lenovo G24-10, AOC 2470W) AND eDP-1 are connected with lid open. eDP-1 MUST be at `preferred,4920x420,1`. Externals MUST be at y=420: AOC 24P1W1 at `0x420` with `transform,1`, Lenovo G24-10 at `1080x420`, AOC 2470W at `3000x420`.

#### Scenario: Boot docked with lid open

- GIVEN t14 is connected to the dock with all 3 externals and lid is open
- WHEN Hyprland session starts and HDM evaluates profiles
- THEN the docked+lid-open profile matches
- AND eDP-1 is positioned at preferred,4920x420,1
- AND AOC 24P1W1 is at 1920x1080@60,0x420,1,transform,1
- AND Lenovo G24-10 is at 1920x1080@60,1080x420,1
- AND AOC 2470W is at 1920x1080@60,3000x420,1

### Requirement: Docked+Lid-Closed Profile

The system MUST define an HDM profile that activates when all three externals are connected with lid closed. eDP-1 MUST be parked at `preferred,-30000x0,1` (off-screen, NOT `disable` — avoids Hyprland#1274). Externals MUST be at y=0: AOC 24P1W1 at `0x0` with `transform,1`, Lenovo G24-10 at `1080x0`, AOC 2470W at `3000x0`.

#### Scenario: Close lid while docked

- GIVEN t14 is docked with all 3 externals active and lid is open
- WHEN the user closes the lid
- THEN HDM switches to docked+lid-closed profile
- AND eDP-1 moves to preferred,-30000x0,1 (off-screen park)
- AND all 3 externals reposition to y=0

#### Scenario: Boot docked with lid closed

- GIVEN t14 is connected to the dock with lid closed at power-on
- WHEN Hyprland session starts
- THEN the docked+lid-closed profile matches
- AND eDP-1 is parked off-screen at -30000x0
- AND externals are at y=0

### Requirement: Undocked+Lid-Open Profile

The system MUST define an HDM profile that activates when only eDP-1 is connected with lid open. eDP-1 MUST be at `preferred,0x0,1`.

#### Scenario: Undock with lid open

- GIVEN t14 is docked with lid open and user undocks
- WHEN external monitors disconnect
- THEN HDM switches to undocked+lid-open profile
- AND eDP-1 is at preferred,0x0,1

### Requirement: Fallback Profile

The system MUST define a fallback profile for unmatched states (e.g., undocked+lid-closed). The fallback SHOULD use `monitor=,preferred,auto,1`.

#### Scenario: No profile matches

- GIVEN t14 has only eDP-1 connected with lid closed
- WHEN HDM evaluates profiles and no condition set matches
- THEN the fallback profile activates
- AND eDP-1 uses preferred resolution at auto position

### Requirement: Profile Matching by Monitor Descriptor

Each profile MUST use `required_monitors` with exact `description` strings matching `hyprctl monitors` output: `"AOC 24P1W1 OTNQ4HA000101"`, `"Lenovo Group Limited LEN G24-10 U5B4GWF1"`, `"AOC 2470W GGZM3HA438259"`. The laptop panel MUST use `name = "eDP-1"` with `monitor_tag = "laptop"`. External monitors MUST use `monitor_tag = "external"`.

#### Scenario: Partial dock connection

- GIVEN only 2 of 3 externals are connected
- WHEN HDM evaluates profiles
- THEN no docked profile matches (all 3 externals required)
- AND the fallback profile activates

### Requirement: TOML Configuration File

The HDM profile configuration MUST be stored as a TOML file at `hosts/t14/hdm/config.toml`. The file MUST define all four profiles and the fallback. The file MUST be wired via the HDM NixOS module (`services.hyprdynamicmonitors`).

#### Scenario: Configuration is valid TOML

- GIVEN the config.toml file exists in the repository
- WHEN parsed by HDM v1.4.0
- THEN all profiles load without error
- AND HDM writes output to `~/.config/hypr/config.d/99_autogenerated-monitors.conf`
