# Proposal: Transfer Nix-generated opencode config from rog to remote (pasar-opencode-remoto)

## Intent

The remote host (172.16.0.12, postmarketOS/OnePlus5) has opencode v1.15.10 installed but zero configuration. Rog has a full, battle-tested opencode setup generated by NixOS + Home Manager. This change bridges that gap by producing a script that rsyncs all platform-independent config from rog to the remote, then installs native aarch64 dependencies on the remote.

## Scope

### IN Scope

- A deploy script at `bin/sync-opencode-remote` in the repo
- rsync transfer of platform-independent config files from rog's `~/.config/opencode/` to remote's `~/.config/opencode/`
- Post-transfer `npm install` on remote for native aarch64 node_modules
- Backup of remote config before overwriting
- Dry-run support (`--dry-run` flag)
- Documentation of API key setup (must be done separately via sops)

### OUT of Scope

- Managing API keys/secrets (already handled by sops + env vars, NOT in generated config)
- Upgrading opencode on the remote (version bump is documented as a risk but not automated)
- Generating config via Nix on the remote (postmarketOS has no Nix)
- Any modifications to shared/opencode/ Nix modules themselves

## Capabilities

| Capability | Priority | Description |
|------------|----------|-------------|
| SYNC-CONFIG | MUST | Transfer all platform-independent files from rog to remote via rsync |
| BACKUP | MUST | Create timestamped backup of remote config before overwriting |
| DRY-RUN | MUST | Support `--dry-run` flag showing what would change without modifying |
| INSTALL-DEPS | MUST | Run `npm install` on remote to get native aarch64 packages |
| SKIP-NODE | MUST | Exclude node_modules/ (x86_64) from transfer |
| DOC-SECRETS | SHOULD | Document API key setup (env vars via .zshrc, not part of script) |

## Approach

### Transfer mechanism: rsync

Both hosts have rsync. Script runs from rog, pushes to remote via SSH.

### Files to include

- `opencode.json` (main config)
- `IDENTITY.md`, `SYSTEM_RULES.md`, `sdd-review-policy.md`
- `skills/`, `commands/`, `plugins/`, `instructions/`, `themes/` directories
- Any `.md`, `.json`, `.jsonc`, `.yaml`, `.yml` files in root

### Files to exclude

- `node_modules/` (x86_64 native binaries, 130M)
- `*.backup`, `skills.backup/`
- `.opencode/` (internal state)

### Post-transfer

- SSH to remote and run `cd ~/.config/opencode && npm install` for native aarch64 deps

### Script structure

```
bin/sync-opencode-remote
  Usage: ./bin/sync-opencode-remote [--dry-run]
  Steps:
    1. Define SRC=~/.config/opencode
    2. Define DST=glats@172.168.0.12:~/.config/opencode
    3. SSH to remote, create backup: mv {DST} {DST}.bak.$(date +%Y%m%d-%H%M%S)
    4. rsync with --archive --delete --dry-run flag (conditional)
       --exclude node_modules/ --exclude '*.backup' --exclude skills.backup/ --exclude .opencode/
    5. SSH to remote, cd {DST} && npm install
```

## Affected Areas

| Area | Impact |
|------|--------|
| `bin/sync-opencode-remote` | NEW — deploy script |
| Remote `~/.config/opencode/` | OVERWRITTEN after backup |
| Rog `~/.config/opencode/` | READ-ONLY (source, not modified) |

## Risks

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| node_modules arch mismatch | Certain | High | Excluded from rsync; native install on remote |
| opencode version diff (1.17.11 vs 1.15.10) | Likely | Medium | Document need to upgrade remote; config is backward-compatible JSON |
| rsync delete removes unknown files | Medium | Medium | Pre-transfer backup is mandatory |
| API keys not transferred | Certain | Low | Documented; user configures via sops on remote separately |
| Script fails mid-transfer | Low | Medium | Backup preserves original state; rsync partial is restartable |

## Rollback Plan

1. Restore from backup: on remote, `mv ~/.config/opencode.bak.{timestamp} ~/.config/opencode`
2. Remote retains old config intact since backup runs before transfer
3. Idempotent: re-running the script re-syncs from scratch

## Dependencies

- SSH access to 172.16.0.12 (passwordless, already configured)
- rsync on both hosts (confirmed on both)
- npm on remote (confirmed, opencode was installed via npm)
- No NixOS changes required — this is a standalone script

## Success Criteria

1. Running `bin/sync-opencode-remote --dry-run` lists all files to transfer without modifying remote
2. Running `bin/sync-opencode-remote` backs up remote config to `.bak.{timestamp}`
3. After transfer, remote `ls ~/.config/opencode/skills/` shows skills present
4. `opencode --version` on remote reports expected config
5. Double-run is idempotent: second run transfers no files (config already in sync)
